# practiceday

## Top-down game (branch: `topdown-game`)

C++20 + [raylib](https://www.raylib.com/) 6.0 starter template.

### Build & run

```sh
cmake -S . -B build
cmake --build build
./build/topdown_game
cmake --build build && ./build/topdown_game
```
